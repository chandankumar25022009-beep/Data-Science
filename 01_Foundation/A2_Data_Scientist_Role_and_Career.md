# A2 — Data Scientist Role & Career

## 1. Who is a Data Scientist?

A Data Scientist is a professional who uses data, programming, statistics, mathematics, and machine learning to solve real-world problems and make data-driven decisions.

### Easy Explanation

A Data Scientist takes raw data, studies it, finds patterns, and uses those patterns to answer questions or make predictions.

### Example

A college has data about:
- Students' attendance
- Marks
- Assignments
- Attendance percentage

A Data Scientist can analyze this data to find patterns related to student performance.

---

## 2. What Does a Data Scientist Do?

A Data Scientist generally performs these activities:

### Step 1 — Collect Data
Collect data from databases, applications, websites, sensors, files, and other sources.

### Step 2 — Clean Data
Fix missing values, duplicate records, incorrect values, and formatting problems.

### Step 3 — Analyze Data
Study the data to find patterns, relationships, and trends.

### Step 4 — Visualize Data
Create charts and graphs to understand and communicate the data.

### Step 5 — Build Models
Use statistics and machine learning to build predictive models.

### Step 6 — Evaluate Results
Check whether the analysis or model produces useful results.

### Step 7 — Communicate Results
Explain findings clearly to other people.

## 4. Data Scientist vs Data Analyst

| Data Analyst | Data Scientist |
|---|---|
| Analyzes existing data | Analyzes data and often builds predictive models |
| Reports trends | Finds patterns and makes predictions |
| Uses SQL, Excel, and Python | Uses Python, SQL, Statistics, and ML |
| Focuses heavily on analysis and reporting | Often works on prediction and machine learning |
| Creates reports and dashboards | Creates analytical and machine learning solutions |

Note: The responsibilities can overlap, and companies may define these roles differently.
