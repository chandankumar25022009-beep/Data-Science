# A5 — Data Sources

## 1. What is a Data Source?

A Data Source is a place, system, device, or method from which data is obtained for analysis or processing.

### Easy Definition

Data Source = The place or method from which we get data.

### Examples

- Database
- Website
- API
- Sensor
- Survey
- Public Dataset
- CSV File
- Excel File


## 2. Why are Data Sources Important?

Data Sources are important because Data Scientists need data to:

1. Perform data analysis
2. Find patterns
3. Create visualizations
4. Build machine learning models
5. Make predictions
6. Support decision-making

### Key Point

Good Data Source → Good Data → Better Analysis


## 3. Main Categories of Data Sources

Data sources can be broadly divided into:

1. Internal Data Sources
2. External Data Sources


## 4. Internal Data Sources

Internal Data Sources are sources that exist inside an organization.

### Examples

- Company databases
- Customer records
- Sales records
- Employee records
- Website activity logs
- Transaction records

### Example

An online shopping company stores customer orders in its own database.

This database is an Internal Data Source.

### Easy Definition

Internal Data Source = Data generated and stored within an organization.


## 5. External Data Sources

External Data Sources are sources that come from outside an organization.

### Examples

- Government datasets
- Public websites
- Research papers
- Public APIs
- Social media data
- Weather data
- Open datasets

### Example

A Data Scientist downloads population data from a government website.

This is an External Data Source.

### Easy Definition

External Data Source = Data obtained from outside an organization.


## 6. Databases

A database is a system used to store and manage data.

Data Scientists and Data Analysts often obtain data from databases.

### Examples

- MySQL
- PostgreSQL
- MongoDB
- SQLite
- Microsoft SQL Server

### Example

A college database may contain:

- Student ID
- Student Name
- Marks
- Attendance
- Course

### Key Point

Database → Stores and manages data


## 7. APIs

API stands for Application Programming Interface.

An API allows software applications to communicate with each other and access or exchange data.

### Example

A weather application can use a weather API to obtain:

- Temperature
- Humidity
- Wind speed
- Weather condition

### Easy Definition

API = A way for applications to communicate and exchange data.


## 8. Websites

Websites can contain useful information that may be used as a data source.

### Examples

- News websites
- Government websites
- E-commerce websites
- Educational websites

### Example

A Data Scientist may collect publicly available product information from a website for analysis, subject to the website's terms and applicable laws.

### Key Point

Website → Can provide publicly available data


## 9. Sensors

Sensors are devices that detect and collect information from the physical environment.

### Examples

- Temperature sensor
- GPS sensor
- Motion sensor
- Pressure sensor
- Heart-rate sensor

### Example

A smart watch can collect:

- Heart rate
- Steps
- Distance
- Activity data

### Key Point

Sensor → Collects data from the physical world


## 10. Surveys

A survey is a method of collecting information by asking questions to people.

### Examples

- Customer satisfaction survey
- Student feedback survey
- Market research survey
- Online questionnaire

### Example

A college asks 500 students:

"What is your favorite programming language?"

The collected responses become a data source.

### Key Point

Survey → Collects information directly from people


## 11. Public Datasets

Public datasets are datasets made available for people to use for research, education, analysis, or other permitted purposes.

### Examples

- Government datasets
- Research datasets
- Open data portals
- Machine learning datasets

### Example

A Data Science student can use a public student-performance dataset to practice data analysis.


## 12. Common Data Files

Data can also be stored in files.

### Common Formats

- CSV
- Excel
- JSON
- XML
- PDF

### Example of CSV

name,marks
Chandan,85
Rahul,80
Aman,75

### Example of JSON

{
  "name": "Chandan",
  "marks": 85
}


## 13. Internal vs External Data Sources

| Internal Data Source | External Data Source |
|---|---|
| Comes from inside an organization | Comes from outside an organization |
| Company database | Government dataset |
| Sales records | Public API |
| Employee records | Public website |
| Customer records | Research dataset |

## 15. Real-Life Example

Suppose an online shopping company wants to understand customer behavior.

It can collect data from:

### Database

Customer orders and transaction records.

### Website

Products viewed by customers.

### API

External information such as delivery or weather data.

### Survey

Customer feedback.

### Sensors

Warehouse or delivery-related device data.

The company can combine these sources and analyze the data.
