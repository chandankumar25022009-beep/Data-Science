# A1 — What is Data Science?

## 1. What is Data?

Data means information or facts that can be collected, stored and analyzed.

Examples:
- Student name
- Student marks
- Attendance
- Sales records
- Temperature
- Website visitors

## 2. What is Data Science?

Data Science is a field that uses data, programming, mathematics and statistics to find useful information, patterns and insights from data.

## 3. Simple Example

Suppose a college has the marks and attendance data of 1000 students.

A Data Scientist can analyze this data to find patterns, such as whether attendance is related to student performance.

## 4. Main Steps of Data Science

Data Collection
↓
Data Cleaning
↓
Data Analysis
↓
Data Visualization
↓
Machine Learning
↓
Prediction / Decision

## 5. Important Definition

Data Science is an interdisciplinary field that uses programming, mathematics, statistics, data analysis and machine learning to extract useful insights from data.

## 6. Remember

Data Science = Data + Programming + Mathematics + Statistics + Analysis + Machine Learning
