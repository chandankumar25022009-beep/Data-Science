# A3 — Types of Data

## 1. What is Data?

Data means information collected in the form of numbers, text, images, videos, records, etc.

### Examples

- Name → Chandan
- Age → 17
- Marks → 85
- Photo → Image
- Video → Video file

---

## 2. Main Types of Data

There are three important types of data:

1. Structured Data
2. Semi-Structured Data
3. Unstructured Data

### Diagram

DATA
│
├── Structured Data
├── Semi-Structured Data
└── Unstructured Data

---

## 3. Structured Data

Structured Data is data organized in a fixed format, usually in rows and columns.

### Example

| ID | Name | Marks |
|---|---|---|
| 1 | Rahul | 80 |
| 2 | Chandan | 85 |
| 3 | Aman | 75 |

### Examples

- Excel tables
- SQL databases
- Student records
- Sales records

### Easy Definition

Structured Data = Data organized in a fixed table-like format.

---

## 4. Semi-Structured Data

Semi-Structured Data does not follow a strict table format, but it still contains some organization or structure.

### Examples

- JSON
- XML
- Email
- Application logs

### Example of JSON

{
  "name": "Chandan",
  "marks": 85
}

### Easy Definition

Semi-Structured Data = Data that has some structure but is not organized like a fixed table.

---

## 5. Unstructured Data

Unstructured Data does not have a predefined tabular structure.

### Examples

- Images
- Videos
- Audio
- Social media posts
- Documents
- PDF files

### Easy Definition

Unstructured Data = Data without a predefined table-like structure.

---

## 6. Quick Comparison

| Type | Structure | Examples |
|---|---|---|
| Structured | Fixed rows and columns | Excel, SQL |
| Semi-Structured | Some organization | JSON, XML |
| Unstructured | No fixed structure | Images, Videos, Audio |

---

## 7. Real-Life Example

Suppose a college stores student information.

### Structured

Student ID, Name, Marks, and Attendance in a database table.

### Semi-Structured

Student information stored in JSON format.

### Unstructured

Student photographs, videos, scanned documents, and voice recordings.

---

## 8. Data Science Uses Different Types of Data

A Data Scientist may work with all three types of data.

Structured Data
       ↓
SQL / Pandas

Semi-Structured Data
       ↓
JSON / XML

Unstructured Data
       ↓
Images / Audio / Video

---

## 9. Remember

Structured → Table

Semi-Structured → JSON / XML

Unstructured → Image / Video / Audio

---

## 10. Interview Question

### Q: What are the main types of data?

Answer: The three main types of data are Structured Data, Semi-Structured Data, and Unstructured Data.
