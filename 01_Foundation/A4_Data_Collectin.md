# A4 — Data Collection

## 1. What is Data Collection?

Data Collection is the process of gathering information from different sources for analysis, research, or decision-making.

### Easy Definition

Data Collection = Collecting useful information from different sources.

### Examples

- Student marks
- Customer information
- Sales records
- Website visits
- Survey responses
- Weather information

---

## 2. Why is Data Collection Important?

Data Collection is important because good-quality data helps us:

1. Understand problems
2. Find patterns
3. Make better decisions
4. Perform data analysis
5. Build machine learning models
6. Make predictions

### Key Point

Good Data → Better Analysis → Better Decisions

---

## 3. Main Types of Data Collection

There are two important categories:

1. Primary Data
2. Secondary Data

---

## 4. Primary Data

Primary Data is data collected directly by a person or organization for a specific purpose.

### Examples

- Surveys
- Interviews
- Questionnaires
- Experiments
- Direct observations

### Example

A college asks 500 students about their preferred programming language and collects the answers directly.

This is Primary Data.

### Easy Definition

Primary Data = Data collected directly from the original source.

---

## 5. Secondary Data

Secondary Data is data that has already been collected by someone else and is used for a new purpose.

### Examples

- Government reports
- Research papers
- Public datasets
- Company reports
- Books
- Websites

### Example

A Data Scientist downloads a public government dataset about population.

This is Secondary Data.

### Easy Definition

Secondary Data = Data already collected by another person or organization.

---

## 6. Primary Data vs Secondary Data

| Primary Data | Secondary Data |
|---|---|
| Collected directly | Already collected |
| Collected for a specific purpose | May be used for a new purpose |
| Surveys and interviews | Reports and public datasets |
| Usually more specific | May be easier and faster to obtain |

---

## 7. Common Sources of Data

Data can come from many sources:

### 1. Databases

Examples:
- MySQL
- PostgreSQL
- MongoDB

### 2. APIs

An API allows software applications to communicate and exchange data.

Example:

A weather application can get weather information from a weather API.

### 3. Websites

Data can be available on websites in different forms.

### 4. Files

Examples:
- CSV
- Excel
- JSON
- XML
- PDF

### 5. Sensors

Sensors can collect information such as:

- Temperature
- Location
- Speed
- Pressure

### 6. Surveys

Organizations can collect information by asking questions to people.
