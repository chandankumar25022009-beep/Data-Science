# A17 — Model Evaluation Fundamentals

## 1. What is Model Evaluation?

Model Evaluation means checking how well a Machine Learning model performs on data.

After training a model, we need to know:

- Is the model making correct predictions?
- How accurate are the predictions?
- Does the model work well on new data?
- Is the model overfitting or underfitting?

Model Evaluation helps us measure the performance of a Machine Learning model.

---

## 2. Why is Model Evaluation Important?

Model evaluation is important because a model may perform well on training data but poorly on new data.

Evaluation helps us:

- Measure model performance
- Compare different models
- Detect overfitting
- Detect underfitting
- Select the better model
- Improve the model
