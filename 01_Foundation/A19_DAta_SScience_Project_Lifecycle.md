# A19 — Data Science Project Lifecycle — Complete Questions

# PART 1 — INTERVIEW QUESTIONS WITH ANSWERS

## Q1. What is the Data Science Project Lifecycle?

The Data Science Project Lifecycle is a systematic process used to solve real-world problems using data.

## Q2. What is the first step of a Data Science project?

The first step is Problem Definition.

## Q3. What is Problem Definition?

Problem Definition means clearly identifying the problem, objective, expected result, users, and success criteria.

## Q4. What is Business Understanding?

Business Understanding means understanding the real-world requirement and business goal behind the project.

## Q5. Why is Business Understanding important?

It helps the Data Scientist understand what problem needs to be solved and what result is expected.

## Q6. What is an objective in a Data Science project?

An objective defines what the project should achieve.

## Q7. What makes a good project objective?

A good objective should be clear, specific, measurable, and relevant.

## Q8. What is Data Collection?

Data Collection is the process of gathering relevant data from different sources.

## Q9. What are common sources of data?

Common sources include databases, CSV files, Excel files, APIs, websites, surveys, sensors, applications, and public datasets.

## Q10. What is Data Understanding?

Data Understanding is the process of examining the structure and characteristics of collected data.

## Q11. What things are checked during Data Understanding?

We check rows, columns, data types, missing values, duplicates, outliers, features, and target variables.

## Q12. What is Data Cleaning?

Data Cleaning is the process of fixing or handling problems in raw data.

## Q13. What are common data-cleaning problems?

Common problems include missing values, duplicate data, incorrect values, wrong data types, inconsistent formats, and outliers.

## Q14. What are missing values?

Missing values are values that are empty, unavailable, or not recorded in a dataset.

## Q15. How can missing values be handled?

Missing values can be removed or filled using suitable methods such as mean, median, or mode.

## Q16. What is duplicate data?

Duplicate data means the same record appears more than once in a dataset.

## Q17. What is EDA?

EDA stands for Exploratory Data Analysis.

It is the process of exploring data to understand patterns, relationships, distributions, and problems.

## Q18. Why is EDA important?

EDA helps us understand the dataset before building a Machine Learning model.

## Q19. What is Data Visualization?

Data Visualization represents data using charts and graphs.

## Q20. Name common types of charts.

Common charts include:

- Bar Chart
- Line Chart
- Histogram
- Scatter Plot
- Pie Chart
- Box Plot

## Q21. What is Feature Engineering?

Feature Engineering is the process of creating, transforming, or selecting useful features for a Machine Learning model.

## Q22. Why is Feature Engineering important?

Good features can help a Machine Learning model learn useful patterns and improve performance.

## Q23. What is Data Splitting?

Data Splitting means dividing a dataset into training, validation, and testing data.

## Q24. What is Training Data?

Training Data is the data used to train a Machine Learning model.

## Q25. What is Validation Data?

Validation Data is used to tune and compare models during development.

## Q26. What is Test Data?

Test Data is used to evaluate the final model on unseen data.

## Q27. What is Model Selection?

Model Selection means choosing a suitable Machine Learning algorithm for a problem.

## Q28. Give examples of regression algorithms.

Examples include:

- Linear Regression
- Decision Tree Regressor
- Random Forest Regressor

## Q29. Give examples of classification algorithms.

Examples include:

- Logistic Regression
- Decision Tree
- Random Forest
- KNN

## Q30. Give an example of a clustering algorithm.

K-Means is a common clustering algorithm.

## Q31. What is Model Training?

Model Training is the process of teaching a Machine Learning model using training data.

## Q32. What is Model Prediction?

Model Prediction is the process of producing an output for new input data using a trained model.

## Q33. What is Model Evaluation?

Model Evaluation measures how well a Machine Learning model performs.

## Q34. What are common classification evaluation metrics?

Common classification metrics are:

- Accuracy
- Precision
- Recall
- F1-Score
- Confusion Matrix

## Q35. What are common regression evaluation metrics?

Common regression metrics are:

- MAE
- MSE
- RMSE
- R² Score

## Q36. What is Model Improvement?

Model Improvement means improving model performance by using better data, features, algorithms, or tuning methods.

## Q37. What is Hyperparameter Tuning?

Hyperparameter Tuning is the process of finding suitable values for model settings to improve performance.

## Q38. What is Cross-Validation?

Cross-Validation is a technique used to evaluate a model using multiple training and validation splits.

## Q39. What is Deployment?

Deployment means making a trained Machine Learning model available for real-world use.

## Q40. What is a Machine Learning API?

An API allows other applications to communicate with a Machine Learning model.

## Q41. What is Model Monitoring?

Model Monitoring means continuously checking a deployed model's performance, errors, input data, and system health.

## Q42. What is Model Drift?

Model Drift occurs when the relationship between input data and target changes over time and model performance decreases.

## Q43. What is Data Drift?

Data Drift occurs when the distribution of input data changes over time.

## Q44. What is Retraining?

Retraining means training a model again using new or updated data.

## Q45. Why is Documentation important?

Documentation makes the project easier to understand, maintain, and reproduce.

## Q46. What is Reproducibility?

Reproducibility means another person can reproduce the project process and results.

## Q47. What is Version Control?

Version Control is a system used to track changes made to project files over time.

## Q48. What is Git?

Git is a Version Control System used to track changes in project files.

## Q49. What is GitHub?

GitHub is a platform used to store, manage, and share Git repositories.

## Q50. What is a README file?

README is a documentation file that explains important information about a project.

# KEY POINT

A Data Science project is not only about creating a Machine Learning model.

It is a complete end-to-end process:

Problem
→ Data
→ Cleaning
→ Analysis
→ Features
→ Model
→ Evaluation
→ Deployment
→ Monitoring
→ Improvement
