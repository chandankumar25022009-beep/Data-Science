# Revision Q&A

## Basic Revision Questions

### Q1. What is Data Science?
**Answer:** Data Science is the field of collecting, processing, analyzing, and interpreting data to find useful information and support decision-making.

### Q2. Why is Data Science important?
**Answer:** Data Science helps organizations understand data, find patterns, make predictions, and make better decisions.

### Q3. What is Data?
**Answer:** Data is a collection of facts, values, observations, or information.

### Q4. What are examples of data?
**Answer:** Names, ages, marks, prices, temperatures, sales numbers, images, and text are examples of data.

### Q5. What is a dataset?
**Answer:** A dataset is an organized collection of related data.

### Q6. What is data analysis?
**Answer:** Data analysis is the process of examining data to find patterns, trends, and useful information.

### Q7. What is data visualization?
**Answer:** Data visualization means representing data using charts, graphs, or other visual forms.

### Q8. What is a pattern in data?
**Answer:** A pattern is a repeated or meaningful relationship found in data.

### Q9. What is a trend?
**Answer:** A trend is the general direction in which data changes over time.

### Q10. What is a Data Scientist?
**Answer:** A Data Scientist uses data, programming, statistics, and analytical techniques to solve problems and generate insights.

## Python and Data Science Revision

### Q11. Why is Python used in Data Science?
**Answer:** Python is easy to learn and has powerful libraries for data analysis, visualization, and machine learning.

### Q12. What is a variable?
**Answer:** A variable is a name used to store a value in a program.

### Q13. What is a list in Python?
**Answer:** A list is a collection of multiple values stored in one variable.

### Q14. What is a loop?
**Answer:** A loop is used to repeat a block of code multiple times.

### Q15. What is an if statement?
**Answer:** An if statement is used to execute code when a condition is true.

### Q16. What is user input?
**Answer:** User input is data entered by a user during program execution.

### Q17. What is a numerical value?
**Answer:** A numerical value is data represented using numbers.

### Q18. What is a string?
**Answer:** A string is a sequence of characters, usually written inside quotes.

### Q19. What is a condition?
**Answer:** A condition is an expression that evaluates to True or False.

### Q20. What is a calculation in Data Science?
**Answer:** A calculation is an operation performed on data to obtain a useful result.

## Data Understanding

### Q21. What is structured data?
**Answer:** Structured data is organized in a fixed format, such as rows and columns in a table.

### Q22. What is unstructured data?
**Answer:** Unstructured data does not follow a fixed tabular structure, such as images, videos, and free-form text.

### Q23. What is numerical data?
**Answer:** Numerical data contains numbers, such as age, marks, price, and temperature.

### Q24. What is categorical data?
**Answer:** Categorical data represents groups or categories, such as gender, city, or product type.

### Q25. Why do we classify data?
**Answer:** We classify data to understand its type and choose suitable methods for processing and analysis.

## Data Science Process

### Q26. What is the first step in a Data Science project?
**Answer:** The first step is to understand the problem and define the objective.

### Q27. Why is data collection important?
**Answer:** Data collection provides the information required for analysis and problem-solving.

### Q28. Why is data cleaning important?
**Answer:** Data cleaning removes or handles errors, missing values, duplicates, and inconsistent data.

### Q29. What is data preprocessing?
**Answer:** Data preprocessing prepares raw data for analysis or machine learning.

### Q30. What is exploratory data analysis?
**Answer:** Exploratory Data Analysis (EDA) is used to understand data using statistics, patterns, and visualizations.

### Q31. What is a data insight?
**Answer:** A data insight is a useful conclusion or understanding obtained from analyzing data.

### Q32. What is prediction?
**Answer:** Prediction means using available data to estimate a future or unknown outcome.

### Q33. What is decision-making using data?
**Answer:** It means using analyzed information and evidence to make better decisions.

### Q34. What is a Data Science project?
**Answer:** A Data Science project uses data and analytical techniques to solve a real-world problem.

### Q35. What is the goal of Data Science?
**Answer:** The goal is to extract useful knowledge and insights from data for solving problems and making decisions.

## Important Python Practice Concepts

### Q36. How do you find the total of numbers in Python?
**Answer:** Use the `sum()` function or add the numbers using a loop.

### Q37. How do you find the number of items in a list?
**Answer:** Use the `len()` function.

### Q38. How do you find the highest value?
**Answer:** Use the `max()` function.

### Q39. How do you find the lowest value?
**Answer:** Use the `min()` function.

### Q40. How do you calculate an average?
**Answer:** Divide the total value by the number of values.

### Q41. How do you check whether a number is even?
**Answer:** Use `number % 2 == 0`.

### Q42. How do you check whether a number is odd?
**Answer:** Use `number % 2 != 0`.

### Q43. How do you check whether a number is positive?
**Answer:** Use `number > 0`.

### Q44. How do you check whether a number is negative?
**Answer:** Use `number < 0`.

### Q45. How do you check whether a number is zero?
**Answer:** Use `number == 0`.
