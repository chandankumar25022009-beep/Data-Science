# A3 — Types of Data: Revision Questions and Answers

## Q1. What is Data?

Data is a collection of facts, values, or information.

## Q2. What are the two main types of data?

Numerical Data and Categorical Data.

## Q3. What is Numerical Data?

Data represented by numbers, such as age and salary.

## Q4. What is Categorical Data?

Data represented by categories, such as city and color.

## Q5. What is Discrete Data?

Countable data, usually expressed as whole numbers.

## Q6. What is Continuous Data?

Measurable data that can contain decimal values.

## Q7. Give two examples of Discrete Data.

Number of students and number of cars.

## Q8. Give two examples of Continuous Data.

Height and temperature.

## Q9. What is Qualitative Data?

Data that describes qualities or categories.

## Q10. What is Quantitative Data?

Data that represents numerical quantities.

## Q11. What is Structured Data?

Data organized in a predefined format, such as rows and columns.

## Q12. What is Unstructured Data?

Data that does not follow a fixed tabular structure, such as images and videos.

## Q13. What is Semi-Structured Data?

Data with some organizational structure, such as JSON and XML.

## Q14. What is Nominal Data?

Categorical data without a natural order.

## Q15. What is Ordinal Data?

Categorical data with a meaningful order.

## Q16. Is color nominal or ordinal?

Nominal, because colors have no natural order.

## Q17. Is Low, Medium, High nominal or ordinal?

Ordinal, because the categories have an order.

## Q18. What does Python's `type()` function do?

It returns the type of a Python object.

## Q19. What is the Python type of 25?

`int`

## Q20. What is the Python type of 5.8?

`float`

## Q21. What is the Python type of "Meerut"?

`str`

## Q22. Which Python library is commonly used to work with tabular data?

Pandas.

## Q23. What is a DataFrame?

A two-dimensional tabular data structure provided by Pandas.

## Q24. How can we select numerical columns in Pandas?

Use `df.select_dtypes(include="number")`.

## Q25. Why is understanding data types important?

It helps us choose suitable analysis and Machine Learning methods.
