# A3 — Types of Data: Interview Questions and Answers

## Q1. What is Data?

Data is a collection of facts, values, or information used for analysis.

## Q2. What are the main types of data?

The main types are Numerical Data and Categorical Data.

## Q3. What is Numerical Data?

Numerical data represents numbers that can be counted or measured.

**Example:** Age, salary, height, and temperature.

## Q4. What is Categorical Data?

Categorical data represents groups, labels, or categories.

**Example:** City, color, blood group, and education level.

## Q5. What is Discrete Data?

Discrete data contains countable values, usually whole numbers.

**Example:** Number of students in a class.

## Q6. What is Continuous Data?

Continuous data can take any value within a range, including decimals.

**Example:** Height, weight, and temperature.

## Q7. What is the difference between Discrete and Continuous Data?

Discrete data is countable, while continuous data is measurable.

## Q8. What is Qualitative Data?

Qualitative data describes qualities or categories rather than numerical quantities.

**Example:** Color, city, and type of vehicle.

## Q9. What is Quantitative Data?

Quantitative data represents numerical quantities.

**Example:** Age, income, and number of students.

## Q10. What is Structured Data?

Structured data is organized in a predefined format, such as rows and columns.

**Example:** A spreadsheet or SQL table.

## Q11. What is Unstructured Data?

Unstructured data does not follow a fixed tabular structure.

**Example:** Images, videos, audio, and free-form text.

## Q12. What is Semi-Structured Data?

Semi-structured data has some organizational elements but does not follow a strict table structure.

**Example:** JSON and XML files.

## Q13. What is the difference between Structured and Unstructured Data?

Structured data follows a predefined format; unstructured data does not follow a fixed tabular format.

## Q14. Is Age Discrete or Continuous Data?

Age can be represented as discrete whole years or as continuous time, depending on how it is measured.

## Q15. Is Temperature Discrete or Continuous Data?

Temperature is generally treated as continuous data.

## Q16. What is Ordinal Data?

Ordinal data contains categories with a meaningful order.

**Example:** Low, Medium, High.

## Q17. What is Nominal Data?

Nominal data contains categories without a natural order.

**Example:** Red, Blue, and Green.

## Q18. Why is understanding data types important in Data Science?

It helps us choose suitable analysis methods, visualizations, and Machine Learning techniques.

## Q19. Give an example of numerical and categorical data.

Numerical: Salary = 25000.
Categorical: City = Meerut.

## Q20. Which Python function checks a value's data type?

The `type()` function checks the data type of a Python value.

**Example:**

```python
age = 20
print(type(age))
```

Output:

```text
<class 'int'>
```

## Quick Revision

* Numerical Data: Numbers
* Categorical Data: Categories or labels
* Discrete Data: Countable values
* Continuous Data: Measurable values
* Structured Data: Predefined organization
* Unstructured Data: No fixed tabular structure
* Semi-Structured Data: Partial organization
* Nominal Data: No natural order
* Ordinal Data: Meaningful order
