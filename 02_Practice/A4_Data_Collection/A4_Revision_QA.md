# A4 — Data Collection: Revision Questions and Answers

## Q1. What is Data Collection?
Data Collection is the process of gathering data for analysis.

## Q2. Why is Data Collection important?
It provides information for analysis and decision-making.

## Q3. What is Primary Data?
Data collected directly for a specific purpose.

## Q4. What is Secondary Data?
Data already collected by another person or organization.

## Q5. Give two examples of Primary Data.
Surveys and interviews conducted directly.

## Q6. Give two examples of Secondary Data.
Government reports and existing public datasets.

## Q7. What is a Survey?
A method of collecting information using questions.

## Q8. What is an Interview?
A method of collecting information by asking questions directly.

## Q9. What is Observation?
Collecting data by watching and recording events.

## Q10. What is an Experiment?
Collecting data by testing something under controlled conditions.

## Q11. What is a Dataset?
A collection of related data used for analysis.

## Q12. What is a Data Source?
The place or system from which data is obtained.

## Q13. What is an API?
An API allows software applications to exchange data.

## Q14. What is Web Scraping?
Extracting data from websites using software tools.

## Q15. What is Sensor Data?
Data collected automatically by sensors.

## Q16. What is Real-Time Data?
Data collected as events occur.

## Q17. What is Historical Data?
Data collected and stored from the past.

## Q18. Name three common Data Collection problems.
Missing values, duplicate records, and incorrect data.

## Q19. Why should a Data Source be reliable?
Reliable sources help produce accurate analysis.

## Q20. What should you check before using collected data?
Check its accuracy, completeness, relevance, reliability, and ethical use.

## Q21. Which Python function collects user input?
The `input()` function.

## Q22. Which Python library is commonly used for tabular data?
Pandas.

## Q23. What is a Pandas DataFrame?
A two-dimensional data structure arranged in rows and columns.

## Q24. How do you check missing values in Pandas?
Use `df.isnull().sum()`.

## Q25. How do you inspect a DataFrame's structure?
Use `df.info()`.

## Quick Revision
- Primary Data: Collected directly
- Secondary Data: Already existing data
- Survey: Questions-based collection
- Interview: Direct questioning
- Observation: Watching and recording
- Experiment: Controlled testing
- API: Software data exchange
- Web Scraping: Extracting website data
- Pandas: Tabular data analysis
