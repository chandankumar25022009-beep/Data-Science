# A4 — Data Collection: Interview Questions and Answers

## Q1. What is Data Collection?
Data Collection is the process of gathering data from different sources for analysis.

## Q2. Why is Data Collection important?
It provides the data required for analysis, decision-making, and Machine Learning.

## Q3. What are the main methods of Data Collection?
Common methods include surveys, interviews, observations, experiments, and existing datasets.

## Q4. What is Primary Data?
Primary data is collected directly by the researcher or organization for a specific purpose.

**Example:** Surveying students about their study habits.

## Q5. What is Secondary Data?
Secondary data is collected by someone else and used for a new analysis.

**Example:** Government reports or public datasets.

## Q6. What is the difference between Primary and Secondary Data?
Primary data is collected directly for a specific purpose, while secondary data already exists.

## Q7. What is a Survey?
A survey collects information from people using questions or forms.

## Q8. What is an Interview in Data Collection?
An interview collects information by directly asking questions to a person.

## Q9. What is Observation?
Observation means collecting data by watching and recording events or behavior.

## Q10. What is an Experiment?
An experiment collects data by testing something under controlled conditions.

## Q11. What is a Dataset?
A dataset is a structured collection of related data used for analysis.

## Q12. What is a Data Source?
A data source is the place or system from which data is obtained.

## Q13. Give examples of Data Sources.
Examples include databases, websites, APIs, surveys, sensors, and public datasets.

## Q14. What is Web Scraping?
Web scraping is the process of extracting data from websites using software tools.

## Q15. What is an API?
An API allows software applications to communicate and exchange data.

## Q16. What is Sensor Data?
Sensor data is collected automatically from sensors such as temperature or motion sensors.

## Q17. What is Real-Time Data?
Real-time data is collected and processed as events occur.

**Example:** Live stock prices.

## Q18. What is Historical Data?
Historical data is information collected and stored from the past.

## Q19. What problems can occur during Data Collection?
Common problems include missing data, incorrect data, duplicate data, bias, and unreliable sources.

## Q20. Why should Data Sources be reliable?
Reliable sources help produce accurate and trustworthy analysis.

## Quick Revision

- Experiment → Controlled testing
